# 逐題評分與補考規格

1. **只問一題**，等待回答。不自動先公開後續題的答案。
2. 回答後評分 0–10，說明正確點、錯誤點、公式／原文依據及可以在教授前說的一句修正版。
3. 重大誤解先給**一個補考問題**；不要在補考前繼續新的主題。補考結束也保留原來的錯誤紀錄。
4. 學習者說很難，拆成更小的子題；算式錯誤指出實際出錯的微分、移項、代入或前提。
5. 口頭報告分為研究問題、方法、理論或實證貢獻、限制四段，練好再整合為一分鐘。

## 教學性分數（非標準化）

| 分數 | 判斷 |
|---:|---|
| 9–10 | 關鍵概念完整正確且理由充分 |
| 7–8 | 主要正確，部分定義或假設需補 |
| 5–6 | 有核心理解，但重要步驟／概念錯誤 |
| 3–4 | 僅少量相關、主要結論錯誤 |
| 0–2 | 缺答或完全錯誤 |

一題答對不表示已通過正式學術考核。猜中選擇題可以再追問理由。

### 本次 Kalman（1960）教學示例

- Q/P 混淆 → 相同 Q/R、不同 A/B 的 P 會怎樣？
- 不會對 u 最小化 → 先算一維二次式，再進入符號 Riccati。
- 模型錯誤與觀測誤差混淆 → 提供兩個 A 不同的閉迴路反例，再單獨確認兩類誤差。
- 一分鐘報告太難 → 將研究目的／方法／貢獻／限制分成四小題。

這是**教學梯度的例子**，不是跨學科必須照抄的題型。
