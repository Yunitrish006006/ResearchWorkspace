## 已確定的可重用學習偏好

1. 原始文獻優先；核對題名、作者、版本、頁碼、式號、實際閱讀範圍。原文與現代教學推導／自編例題分開。
2. **一次只問一題**，先讓使用者用自己的話回答，之後才依答題內容給 0–10 分、錯誤分析與修正版。
3. 不熟的觀念先以一個小例子教學再補考，不能一口氣出所有考題。答對再提高難度。
4. 一分鐘報告若感到困難，拆成研究目的、方法、貢獻、限制，逐段練習再整合。
5. 依使用者要求，把問答、錯誤、補考、手算、教授追問與講稿回寫至 GitHub 的 canonical thesis repo，保留歷史，不當成聊天逐字稿。
6. 不捏造已回答題目、分數、原始頁碼、已向教授報告或推送成功的狀態。
7. 單篇論文導讀預設只講該論文，不混入使用者其他研究成果；新要求優先。
8. 只有在請求時產生 HTML／講稿或修改檔案；一般問答不需要預設生成簡報。

## 所有權

ResearchWorkspace 儲存 Skill 與流程規範；Three-Factor-Digital-Twin 儲存原始論文、真實研究資料、筆記、講稿。不要把研究結論複製進 workspace，也不要在可重建的 .research-index 快取保存長期偏好。
