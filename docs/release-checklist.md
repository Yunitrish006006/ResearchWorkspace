# Research release / submission checklist

## Source and evidence

- [ ] Canonical thesis repository HEAD is known and pushed.
- [ ] ResearchWorkspace audited snapshot drift is understood.
- [ ] Claim-to-Evidence Matrix has no accidental unsupported upgrades.
- [ ] E1–E9 status is current; pending/conditional evidence stays labeled.
- [ ] Synthetic, real target-point, public benchmark and intervention evidence remain separated.
- [ ] Strong baseline/adverse results are retained.

## Reproducibility

- [ ] ResearchWorkspace Node validators pass.
- [ ] Flutter analyze/test/Wasm build passes.
- [ ] Source-first inventory passes.
- [ ] Relevant thesis experiment/result verification scripts pass.
- [ ] Runtime verification events record actual pass/fail where used.
- [ ] Research Replay checkpoint is available for consequential agent work.

## Thesis-facing artifacts

- [ ] Chinese thesis source is synchronized with method/evidence status.
- [ ] IEEE manuscript uses the same bounded claims/results.
- [ ] Figures match current metrics and method labels.
- [ ] Presentation and speaker notes do not exceed thesis evidence.
- [ ] Generated DOCX/PDF are rebuilt after source/figure changes.
- [ ] Artifact Drift reports no unexplained warning.

## Delivery

- [ ] GitHub Pages production Flutter viewer builds successfully.
- [ ] Legacy 3D viewer remains usable as rollback/debug surface.
- [ ] ResearchWorkspace parity ledger passes.
- [ ] TotemWorkspace audited reference has not drifted without re-audit.
- [ ] No secrets, absolute local paths, local indexes or private prompt text are in published artifacts.
